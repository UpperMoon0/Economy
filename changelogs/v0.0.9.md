# NsTut Economy 0.0.9

## Multi-loader and Multi-version Expansion

- Added official support for Fabric 1.20.1, Forge 1.20.1, Fabric 1.21.1, and NeoForge 1.21.1.
- Updated release publishing to build and deploy separate, loader-specific jars for each supported target with accurate platform and Java runtime metadata.

## Fluid Tank & Automation Parity

- Enforced atomic bucket transfers on Fabric so nearly full tanks refuse bucket insertion rather than destroying excess fluid.
- Added dynamic bucket resolution for registered modded fluids on Fabric via `BuiltInRegistries.FLUID`.
- Exposed Fabric Transfer API storage (`FluidStorage.SIDED`) on Fabric 1.20.1 and 1.21.1 for tanks when external automation is enabled in configuration.
- Exposed NeoForge `Capabilities.FluidHandler.BLOCK` on NeoForge 1.21.1 for tanks when external automation is enabled in configuration.
- Added missing singular `data/economy/loot_table/blocks/tank.json` loot table for Minecraft 1.21.1.

## UI & Integration

- Integrated OpenUI MC 0.0.6 container input and rendering enhancements across all supported loaders.
