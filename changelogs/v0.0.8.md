# NsTut Economy 0.0.8

## OpenUI migration and interface polish

- Rebuilt the Market Terminal, Vault, and Fluid Tank interfaces on OpenUI MC 0.0.4.
- Added responsive layouts, clipped overflow, consistent no-shadow text, semantic status badges, and improved light/dark theme contrast.
- Corrected Portfolio `LIVE` and current-value badge colors, including their hover states.
- Added coordinate-derived ellipsis boundaries across Browse, detail orders, Active Orders, Trade History, Portfolio holdings, and Containers so long modded names and values cannot collide with neighboring columns or actions.
- Added clipped ping-pong overflow animation to all Portfolio and Container summary cards so long localized values remain readable without crossing card boundaries.
- Placed Container mode and capacity-status badges on one row and added explanatory hover tooltips for every badge state.
- Wrapped deferred foreground tooltips so virtual-list clipping cannot cut them off or force excessively wide single lines.
- Rebalanced Product Details so the chart, sell/buy order books, personal orders, and action button retain distinct vertical regions.
- Resolved Product Details fluid titles from the client fluid registry, with a readable path fallback instead of exposing raw fluid IDs.
- Replaced bracketed seller labels in the Product Details order books with semantic server/player badges and clipped ping-pong overflow animation.
- Removed the redundant Browse page title and normalized edit/confirmation dialogs with clear shells, compact spacing, and right-aligned actions.
- Localized the remaining active-order quantity and server-seller labels.
- Kept Tank transfer annotations aligned with the native processing slot and separated Tank/Vault labels and panels from player inventory slots.
- Added geometry regression tests for the Tank and Vault container screens.

## Fluid Tank reliability

- Added direct Forge fluid capability support for pipes and other automation.
- Improved bucket and compatible fluid-container interaction, server synchronization, and transfer behavior.
- Preserved the Tank's market modes and market-connected fluid storage behavior.
- Limited Tank synchronization to tracking clients and removed eager transfer diagnostics from inventory hot paths.
- Kept direct automation independent from market-only storage modes and documented that contract.

## Packaging and dependencies

- Economy now requires OpenUI MC 0.0.4 or newer.
- CurseForge uploads declare OpenUI MC project `1661978` as a required dependency.
- CI builds OpenUI MC 0.0.4 before compiling and testing Economy.
- Release metadata now identifies Economy as both a client and server mod.
