# Release Changelog: Version 0.0.6

This document details the changes implemented between **version 0.0.5** and **version 0.0.6**.

---

# Section 1: User-Friendly Changelog

### Fluid Commodities and Market Orders

- **Unified Commodity Market**: Items and fluids now share the same Browse catalog, product details, order book, active-order list, trade history, charts, portfolio, and server-order commands.
- **Fluid Sell Orders**: Fluid sell orders reserve their requested amount from eligible Tanks when created.
- **Fluid Buy Orders**: Trades check that the buyer has enough compatible Tank capacity before taking payment or delivering fluid.
- **Safe Cancellation**: Cancelling a fluid sell order restores its remaining reserved fluid to the owner's Tank network.
- **Persistent Fluid Orders**: Fluid commodity type and reserved fluid data are saved and restored across world reloads.
- **Canonical Fluid Listings**: Only source/container-compatible fluids appear in selectors and command suggestions. Flowing water, flowing lava, and equivalent duplicate variants are excluded.
- **Single Server-Order Syntax**: `/economy serverorder buy|sell <commodity> <qty> <price>` now accepts either an item or a fluid ID without separate command branches.

### New Fluid Tank Block

- **128,000 mB Storage**: Added an owner-linked Fluid Tank that stores one compatible fluid at a time.
- **Fluid Container Slot**: Buckets, cells, and other Forge-compatible fluid containers can transfer fluid through the Tank screen.
- **Market Modes**:
  - `BOTH`: Supplies Sell Orders and receives bought fluids.
  - `INPUT ONLY`: Supplies Sell Orders but does not receive purchases.
  - `OUTPUT ONLY`: Receives bought fluids but does not supply Sell Orders.
- **Custom Tank Screen**: Added a centered dark-theme screen with a tiled fluid preview, a processing slot, player inventory, and a single compact `current / maximum` amount line.
- **World Rendering**: Tank fluid renders on the front face with corrected depth/pixel alignment and preserves the source texture's aspect ratio by tiling and cropping instead of stretching.
- **Complete Resource Data**: Added the Tank recipe, loot table, blockstate, block/item models, texture, mining tags, language entries, and creative-tab item.

### Tank Transfer and Synchronization Fixes

- **One-Bucket Transfer Fix**: Fixed the case where filling a container from exactly `1,000 mB` produced a ghost filled bucket without reducing the Tank.
- **Authoritative Server State**: Container results and Tank fluid changes are committed together on the server and explicitly synchronized to clients.
- **Modded Container Diagnostics**: Added detailed transfer logging for capability contents, simulated results, committed slot changes, fluid changes, and sync recipients.

### Market Terminal Layout and Filtering

- **Item/Fluid Filters**: Browse, Active Orders, and Trade History can be filtered by `All`, `Items`, or `Fluids`.
- **Clear Two-Line Controls**: Filter buttons now show a concise semantic heading on top and the current selection below:
  - Browse: `Activity`, `Product`, `Sort`
  - Active Orders: `Order`, `Product`, `Sort`
  - Trade History: `Trade`, `Product`, `Sort`
- **Compact One-Row Filters**: Each screen keeps its three filter controls on one row while retaining a full-width search field.
- **Relevant Browse Results**: Browse only lists commodities with an active order or trade history. Products that have never participated in the market are no longer shown.
- **Grid and Row Views**: Browse defaults to a compact grid and includes a Grid/Rows toggle. The selected view is persisted in `config/economy-client.properties`.
- **Responsive Cards**: Grid cards place order count under the price; row cards keep order count right-aligned.
- **Overflow-Safe Order Rows**: Long order content is clipped to its viewport and moves with a bidirectional ping-pong marquee.
- **Unified Coin Marquee**: The Coin icon moves together with its price text instead of remaining fixed while the text scrolls.
- **Safe Order Cancellation**: Cancelling an order from Product Details or Active Orders now requires confirmation and explains what will be restored.
- **Accurate Sell Stock**: Selecting or entering a valid commodity refreshes its authoritative Vault or Tank stock before creating a Sell Order.
- **Buy-Only Infinite Orders**: The infinite-quantity control is hidden for Sell Orders and its state is cleared when switching to Sell mode.

### Containers Dashboard

- **Renamed Navigation**: The `Vaults` tab is now `Containers`.
- **Vault and Tank Overview**: The dashboard lists both container types with their dimension, coordinates, mode, capacity, stored contents, and utilization.
- **Combined Statistics**: Summary cards show Vault count, Tank count, total stored items, and total stored fluid.
- **Portfolio Integration**: Stored Tank fluids participate in portfolio holdings and asset-value calculations.

### Consistent Quantity and Currency Display

- **Shared Compact Formatting**: Money, item counts, fluid amounts, order counts, and container totals use one formatting implementation with `k`, `m`, `b`, and `t` suffixes.
- **Suffix Spacing Fix**: Compact suffixes remain attached to their numbers, such as `1k`, `2.5m`, and `128k mB`.
- **Fluid Units**: Fluid quantities are consistently displayed in millibuckets instead of mixing bucket and mB formats.
- **Custom Chat Coin Glyph**: Balance, payment, administration, server-order, and market notification messages use the mod's Coin glyph rather than a generic currency character.

### Test Coverage

- Expanded and reorganized the automated test suite to cover:
  - item commodity storage and item/fluid identity separation;
  - fluid order packet metadata and Tank fluid NBT round trips;
  - Tank market modes and capacity rules;
  - one-bucket Tank fill and drain behavior;
  - canonical fluid filtering;
  - compact number and fluid formatting;
  - client Grid/Rows preference persistence;
  - ping-pong marquee offsets;
  - Tank recipes, loot tables, tags, and other resource data;
  - shared two-line button sizing.

# Section 2: Technical Changelog

### Commodity and Order Model

- Added `FluidCommodity` as an `ICommodity` implementation with registry-backed IDs and fluid-stack creation.
- Extended `Order` with reserved `FluidStack` collections alongside reserved `ItemStack` collections.
- Added commodity-type metadata and serialized `ReservedFluids` data to `EconomyOrderData.OrderSnapshot`.
- Updated order creation, matching, partial execution, cancellation, and restoration paths to dispatch by commodity type.
- Added fluid-aware equality so item and fluid registry IDs cannot collide as commodities.
- Updated market packets and DTOs to carry commodity type through creation, cards, details, active orders, history, and holdings.

### Tank Storage and Persistence

- Added `TankBlock`, `TankBlockEntity`, `TankMenu`, and `TankManager`.
- Persisted owner Tank locations by dimension in `EconomyAccountData`.
- Added Tank registration/unregistration lifecycle handling and cross-dimension lookup.
- Added mode-aware `count`, `capacity`, `extract`, `insert`, and rollback helpers.
- Added client block-entity synchronization packets and explicit block updates for container transfers.

### Market and Command Integration

- Updated `MarketNetwork` to:
  - reserve and restore fluids;
  - validate item/fluid stock and compatible destination capacity;
  - include fluids in catalog cards, details, history, active orders, portfolio, and container sync;
  - resolve fluid display names and textures;
  - synchronize Tank mode changes.
- Reworked `/economy serverorder` commodity resolution and suggestions to support item and canonical fluid IDs through the same syntax.
- Added `CommodityUtil` for canonical fluid detection and shared commodity-type filtering.

### Client UI Framework

- Added `ScrollGrid` for the Browse grid layout.
- Added `MarketClientPreferences` for persisted Grid/Rows selection.
- Added reusable two-line label measurement and rendering to `ButtonWidget`.
- Added `UiAnimationUtil` for deterministic ping-pong marquee motion.
- Centralized commodity icon rendering and fluid-aware quantity formatting in market views.
- Renamed the Vault overview implementation to the combined Containers overview.

### Formatting and Coin Rendering

- Expanded `EconomyFormatUtil` with shared item, fluid, commodity, and counted-noun formatting.
- Removed the space between compact values and suffixes.
- Added `CoinText` and a custom font provider so command/chat components can render the mod's Coin texture inline.

### Build and Version

- Updated the project version to **0.0.6**.
- Target remains **Minecraft 1.20.1** with **Forge 47.4.21**.
