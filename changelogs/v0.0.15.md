# Economy 0.0.15

## Market navigation

- Default the market product list to Active, showing products with at least one order. All still includes inactive, previously traded products.
- Add Status as the first filter in the exact item variant picker: Active (default), Inactive, and All. Combine status with the existing metadata search, metadata filters, and sorting.
- Fix corrupted bullet separators, ellipses, and infinity symbols in variant tooltips, order rows, and order summaries across all supported Minecraft versions.

- Keep the complete variant catalog in each visible Browse product so the picker can reveal inactive siblings, including products with only one active variant. Browse prices and activity summaries still use the matching variants.

## Fluid Tank readability

- Show overflowing fluid names, amount/capacity, percentage labels, and subtitles with a clipped marquee; text that fits stays still.
- Reserve the container transfer column so fluid information stays clear of the native Input/Output slots.
- Remove the redundant fluid-container transfer instruction line while keeping the Input/Output slot labels.

## Dependencies and documentation

- Require OpenUI MC 0.0.12 or newer. Compile against 0.0.12 and pin CI builds to its released source commit.
- Document the active defaults, variant status meanings, inactive variant access, Tank text behavior, and matching OpenUI installation requirements.

## Account and settlement correctness

- Retire deleted or reloaded player/team account handles so stale references cannot mutate replacement accounts or overwrite saved balances; bind persistence to the active handle.
- Install new accounts before starting-balance callbacks so addons can safely initialize another account or look up the same handle without repeating starting credit.
- Reject cancellation, editing, and recursive execution of orders participating in settlement, including the counterpart order during matching. Payment pre-events remain cancellable.
- Clamp affordable quantities before integer conversion, fixing valid small item/fluid purchases by buyers with large balances.
- Document server-thread requirements, trusted addon access, account handle lifetime, and callback mutation rules, with shared regression coverage across all three supported Minecraft versions.
