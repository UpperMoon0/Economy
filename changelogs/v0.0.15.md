# Economy 0.0.15

## Market navigation

- Default the market product list to Active, showing products with at least one order. All still includes inactive, previously traded products.
- Add Status as the first filter in the exact item variant picker: Active (default), Inactive, and All. Combine status with the existing metadata search, metadata filters, and sorting.
- Fix corrupted bullet separators, ellipses, and infinity symbols in variant tooltips, order rows, and order summaries across all supported Minecraft versions.

## Fluid Tank readability

- Show overflowing fluid names, amount/capacity, percentage labels, and subtitles with a clipped marquee; text that fits stays still.
- Reserve the container transfer column so fluid information stays clear of the native Input/Output slots.
- Remove the redundant fluid-container transfer instruction line while keeping the Input/Output slot labels.

## Dependencies and documentation

- Require OpenUI MC 0.0.12 or newer. Compile against 0.0.12 and pin CI builds to its released source commit.
- Document the active defaults, variant status meanings, inactive variant access, Tank text behavior, and matching OpenUI installation requirements.
