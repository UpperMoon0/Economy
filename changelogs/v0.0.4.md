# Release Changelog: Version 0.0.4

This document details all changes implemented between **version 0.0.3** and **version 0.0.4**.

---

# Section 1: User-Friendly Changelog

### Interactive Order Editing Modal (`EDIT ORDER`)
- **Full Order Editing**: Edit existing active orders directly from `MY ORDERS` without needing to cancel and recreate them.
- **Quantity & Price Inputs**: Form fields with focused text highlighting, active typing support, backspace, and cursor position tracking.
- **Infinite Toggle Option**: Added a compact `[ ∞ ]` button for buy orders with hover tooltip explanation.

### Chart Pagination, History Scroll & Live Snap
- **15-Timestep Windowing**: Product Details and Portfolio performance charts are now bounded to 15 visible timesteps (`MAX_VISIBLE_CHART_STEPS = 15`), preventing chart node squishing as history grows.
- **Mouse Wheel History Scroll**: Scroll back through historical timesteps using the mouse wheel while hovering over line charts.
- **Snap-to-Live Button (`▶ LIVE`)**: Displays an interactive green badge on charts when scrolled into history. Clicking `▶ LIVE` instantly snaps the chart view back to real-time.
- **Formatted Date & Timestamp Tooltips**: Hovering over chart nodes now displays real-world timestamps (`MM/dd HH:mm:ss`) alongside price and volume metrics.

### Trade Notifications & Counterparty Tracking
- **Detailed Trade Alerts**: Order execution chat messages now display the counterparty player (or Server) and total order cost:
  - *Buyer*: `[Market] Order Matched! Bought 10x Iron Ingot for 5 coins each (Total: 50 coins) from Steve.`
  - *Seller*: `[Market] Order Matched! Sold 10x Iron Ingot for 5 coins each (Total: 50 coins) to Steve.`

### Smart Portfolio Deduplication & Layout Polish
- **Duplicate Snapshot Suppression**: Portfolio snapshots automatically ignore identical consecutive points when opening the UI, preserving actual historical trade data points.
- **No Text Truncation**: Corrected name truncation math in Active Orders and Trade History so long commodity names (e.g., `Iron Ingot`, `Iron Axe`) display in full.
- **Right-Margined Action Buttons**: `[ Edit ]` and `[ Cancel ]` buttons now sit cleanly inside card borders with proper padding.
- **Compact Multi-Line Tooltips**: Bounded tooltip text wrapping to 150px with explicit `\n` line break formatting.

# Section 2: Technical Changelog

### GUI Architecture & Modal Overlay (Z-Depth 400)
- **Edit Order Modal Layering**:
  - Implemented `renderEditOrderModal` in `MarketScreen.java` rendering dark dim backdrop (`0xEE000000`) and modal card at Z-depth 400.
  - Resolved input box rendering by calling `editQtyField.getEditBox().render(g, mx, my, 0)` and `editPriceField.getEditBox().render(g, mx, my, 0)` at Z-depth 400.
  - Updated `EditBoxWrapper.setValue` to set cursor position to `newVal.length()`, appending typed digits naturally.

### Chart Pagination & Pixel-Exact Hit Testing
- **Chart Windowing & Panning**:
  - Added `detailChartOffset` and `portfolioChartOffset` variables bounded by `MAX_VISIBLE_CHART_STEPS = 15`.
  - Added `mouseScrolled` handlers in `MarketScreen.java` to adjust chart offsets.
- **Exact Live Button Bounds**:
  - Recorded exact rendered bounding boxes (`detailLiveBtnX/Y/W/H` and `portfolioLiveBtnX/Y/W/H`) directly in `render()` to guarantee 100% pixel-accurate click detection in `mouseClicked`.

### Trade Notifications & Counterparty Resolution
- **Counterparty Formatting**:
  - Updated `Order.notifyPlayerTrade` in `Order.java` to accept `otherName` (Player username or `"Server"`) and compute total trade price (`unitPrice * quantity`).

### Smart Portfolio History Deduplication
- **Snapshot Equality Check**:
  - Added deduplication check in `addPortfolioPoint` inside `EconomyAccountData.java`: compares `last.netWorth`, `last.balance`, and `last.assets` with incoming values and ignores duplicate consecutive snapshots.
