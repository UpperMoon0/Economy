# Economy 0.0.23

- Expose the new read-only `MarketPriceQuotes.quoteItem(String)` server-side API to Economy-compatible addons.
- Quote from the Market's existing ask, bid or latest trade, returning empty when no validated price is available.
- Keep market implementation and OrderManager internal; addons apply their own price-risk and payout limits.
- Preserve OpenUI MC 0.0.16+ and stable existing Economy account/transfer APIs.
- Remove the always-visible storage valuation diagnostic from the Portfolio layout on all supported versions; valuation freshness tracking and safeguards remain intact.

This version is the minimum dependency for Economy Bounties' dynamic automatic order valuation. It replaces the previous 0.0.22 integration build rather than republishing different bytes under the same immutable version.
