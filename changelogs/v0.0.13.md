# Economy 0.0.13

### Variant-aware item commodities

- Add exact item commodity identities for stacks whose metadata/components differ, while preserving base-item matching for plain stacks.
- Keep exact variants distinct across Vault counting/extraction, escrow, active orders, trade history, market browse/detail views, and order packet round trips.
- Preserve canonical variant descriptors in trade history so historical exact products can be reconstructed after the last active order disappears.
- Allow another player to open a historical exact product and create a new buy order without already owning that exact stack.

### Market UI

- Group exact metadata variants under their registered base item in Browse instead of rendering every variant as an indistinguishable top-level product.
- Add a variant picker with exact rendered item icons, vanilla tooltip metadata, prices, and order counts before opening a variant market.
- Make market and new-order search metadata-aware by indexing the reconstructed vanilla/modded item tooltip, while keeping hashes hidden from normal presentation.
- Add a Vault/Tank picker for sell orders so players can select the exact stored stack variant directly instead of typing or guessing a commodity id.
- Show exact-variant labels and metadata-aware names throughout existing detail/search/confirmation surfaces.
- Polish exact-variant selection UX with marquee detail titles, searchable Vault/Tank holdings, and the storage picker positioned directly below commodity search.
- Wrap picker guidance text and keep two-line variant rows non-redundant by showing the item/custom name on the first line and exact metadata only on the second.
- Consolidate SELL commodity selection into one storage-backed search field: focusing it browses owned Vault/Tank holdings inline, exact variants show metadata and owned quantity, and the separate storage-picker modal/button is removed.
- Require OpenUI MC 0.0.11 for the variant UI, including safe overlay depth above native item rendering and the updated text-wrapping behavior.

### Networking and correctness

- Bound exact-variant descriptor synchronization both per packet and across the entire Browse refresh: each packet stays below the transport ceiling and total descriptor traffic is capped at 1 MiB, with strict ordered truncation so lower-priority history can never bypass an omitted active-order/Vault descriptor.
- Use reset/append semantics for descriptor chunks so multi-packet syncs rebuild the client cache without dropping continuation entries.
- Ignore descriptors that cannot fit the protocol UTF/string budget instead of allowing one oversized entry to break market browsing; the server remains authoritative for commodity resolution.
- Validate ledger-reconstructed stacks against the exact commodity id before using them for details or order creation.

### Testing

- Add packet regression coverage proving descriptor sync chunks stay within the byte budget and preserve all syncable entries.
- Extend real Forge GameTest coverage with a ledger-only exact variant that has no active order and no matching buyer Vault stock, including successful buy-order creation.
