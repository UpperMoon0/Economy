# Economy v0.0.18

- Fixed a Market item-search crash when free text such as `raw ru` reaches exact commodity lookup in mod packs with permissive Minecraft identifier validation.
- Validate optional exact-ID lookups against Economy's own ID rules across all supported Minecraft families. Invalid or incomplete IDs remain ordinary search text; valid item, fluid, and exact-variant lookups retain their existing behavior.
- Added regression coverage for spaces, invalid characters, incomplete IDs, repeated typing/deleting, and valid exact IDs.
