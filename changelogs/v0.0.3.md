# Release Changelog: Version 0.0.3

This document details all changes implemented between **version 0.0.2** and **version 0.0.3**.

---

# Section 1: User-Friendly Changelog

### Custom Vault Storage Container UI & Modes
- **Custom Dark Sleek UI**: Replaced the vanilla chest container screen with a custom dark themed design.
- **Wider Compact Layout**: Redesigned the 54-slot Vault container grid into a wider, shorter layout that reduces vertical height and centers player inventory slots cleanly.
- **Vault Mode Configuration**: Added top-header mode toggle button with 3 operational modes:
  - **`[ BOTH ]` (Default)**: Used for both Sell Orders (input) AND receiving bought items (output).
  - **`[ INPUT ONLY ]`**: Items inside are ONLY extracted for Sell Orders; bought items will NOT enter this Vault.
  - **`[ OUTPUT ONLY ]`**: Bought items are deposited here; items inside are NOT detected for Sell Orders.

### Market Terminal & Catalog Enhancements
- **Unified Global Price**: Catalog cards, order books, and price trend charts now use shared price logic to show the exact same global price (cheapest active sell offer).
- **Price Change Percentage Indicator**: Shows the percentage price change from the last distinct price (+400.00% in Green, -15.50% in Red, or No Change in Gray).
- **Compact Number Formatting**: Automatically formats large values with human-readable suffixes (k for thousands, m for millions, b for billions, t for trillions, e.g. `14.76 k`).
- **Right-Aligned Portfolio Value Badge**: The Portfolio performance chart now displays a right-aligned current Net Worth badge matching the Product Details chart layout.
- **Full Commodity Directory**: Selecting `Filter: All` displays all tradeable commodities with a known price, even if they currently have 0 live orders.

### Notifications & UX Polish
- **In-Chat Trade Notifications**: Both buyer and seller receive system chat messages when an order matches (`[Market] Order Matched! Bought 10x Iron Ingot for 100 coins.`).
- **In-Chat Payment Notifications**: Payments via `/pay` send formatted chat notifications and play the money sound effect to both payer and recipient.
- **Solid Opaque Dropdown List**: The item search autocomplete dropdown is now fully solid and drawn on top of form fields to eliminate text overlap.
- **Order Progress Truncation**: Truncated long fulfillment text in `MY ORDERS` (`(90% filled)`) to prevent text overlap with the `[ Cancel ]` button.
- **Bounded Multi-Line Tooltips**: All tooltips are bounded to a fixed maximum width to wrap text into clean, multi-line cards without stretching across the screen.

# Section 2: Technical Changelog

### Architecture & Networking
- **Vault Mode Data Synchronization**:
  - Added `VaultMode` enum (`BOTH` id=0, `INPUT` id=1, `OUTPUT` id=2) to `VaultBlockEntity.java` with NBT `Mode` tag persistence.
  - Registered `ToggleVaultModePacket` in `MarketNetwork.java` (`C2S`) to cycle mode by `BlockPos` and immediately update `ContainerData` (`vm.setData(0, vault.getMode().id)`).
  - Updated `VaultManager.java` storage and extraction methods (`countItemInVaults`, `extractItemFromVaults`, `insertItemStacksToVaults`) to filter vaults by `VaultMode`.

- **Unified Global Price Calculation**:
  - Implemented `MarketNetwork.getGlobalPrice(OrderManager orderManager, String itemId)` returning `cheapestAsk != null ? cheapestAsk : (highestBid != null ? highestBid : lastTradePrice)`.
  - Replaced ad-hoc price parsing in `sendItemList` and `sendItemDetail` with `getGlobalPrice`.

- **Price Change Percentage Calculation**:
  - Added `priceChangePercent` field to `ItemCardData` record and updated packet codecs (`writeDouble` / `readDouble`).
  - Added trade history search algorithm in `sendItemList` and `buildDetail` to find the last distinct price `prevP != curP`.
  - If no distinct previous price exists in history, initializes `priceChangePercent` to `Double.NaN` (which formats as `"No Change"` in gray `#9E9E9E`).

### GUI Layout & Z-Index Management
- **VaultScreen & VaultMenu Grid Layout**:
  - Reconfigured 54 slots in `VaultMenu.java` to `col + row * 18` (`startX = 12, startY = 36`).
  - Centered player inventory at `playerInvX = 93, playerInvY = 114` and hotbar at `hotbarY = 174`.
  - Adjusted `VaultScreen.java` bounds to `imageWidth = 348, imageHeight = 200, inventoryLabelY = 102`.
- **Search Dropdown Z-Level Overlay**:
  - Added `g.pose().pushPose()` and `g.pose().translate(0, 0, 300)` in `MarketScreen.renderItemDropdown` to elevate the dropdown overlay above form text fields in Z-space.
  - Set fill color to solid opaque `0xFF0E0E1A`.
- **Multi-Line Tooltip Formatting**:
  - Replaced single-component tooltip calls with `this.font.split(Component.literal(tooltip), 180)` in `MarketScreen.java` and `VaultScreen.java`.

### Decoupled Utilities & Automated Testing
- **EconomyFormatUtil Decoupling**:
  - Extracted pure math and formatting functions (`formatCompact`, `formatPriceChange`, `getPriceChangeColor`) into standalone class `EconomyFormatUtil.java` in `com.nstut.economy.util`.
  - Removed headless Minecraft registry dependencies from formatting utilities.
- **Automated Test Suite**:
  - Created `VaultModeTest.java` testing `VaultMode.byId(...)` cycling and fallback logic.
  - Created `CompactFormatTest.java` testing compact number formatting across small numbers, thousands (`k`), millions (`m`), billions (`b`), trillions (`t`), `BigDecimal`, `long`, `double`, and `String` overloads.
  - Created `PriceChangeTest.java` testing positive, negative, and `Double.NaN` price change formatting.

### Clean Up & Removals
- Removed outdated single-vault command `.then(Commands.literal("vault")...)` from `EconomyCommands.java`.
- Removed legacy single-vault helper `VaultManager.getVaultRecord(UUID owner)`.
