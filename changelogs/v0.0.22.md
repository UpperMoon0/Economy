# Economy 0.0.22

- Update the OpenUI MC compile and client-runtime baseline to **0.0.16**, retaining compatibility with later versions through the runtime dependency ranges.
- Keep the stable top-level `com.nstut.economy.api` addon API available to **Economy Bounties 0.1.0** for escrow, claims and generated-bounty payouts.
- Rebuild the 1.20.1 Forge and Fabric artifacts against the updated OpenUI dependency. No Market, Vault or Tank UI redesign is included in this version.

This version is required by the updated Economy Bounties Bounty Board and creative-tab implementation.
