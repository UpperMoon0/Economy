# Release Changelog: Version 0.0.5

This document details all changes implemented between **version 0.0.4** and **version 0.0.5**.

---

# Section 1: User-Friendly Changelog

### Infinite Buy Order Editing & Conversion
- **Seamless Infinite Toggle Conversion**: Edit active infinite buy orders to non-infinite orders directly in the `EDIT ORDER` modal.
- **Smart Quantity Input**: Typing a numeric quantity into the `EDIT ORDER` quantity field automatically turns off infinite mode and sets the quantity. Typing digits into a field containing `[ ∞ ]` automatically clears the infinity symbol and replaces it with the typed number.
- **Toggling Infinite Off**: Clicking the `[ ∞ ]` button to turn off infinite mode automatically fills the quantity text field with the existing order quantity or a valid default quantity (`1`), preventing invalid quantity errors.
- **Execution & Quantity Fixes**: Fixed partial execution and trade handling for infinite buy orders so trades do not cap or zero out order quantities unexpectedly.

### Active Orders Filtering & Sorting
- **Active Orders Filter Button**: Added interactive `Filter` button in the Active Orders subtab:
  - `All Orders`: Displays all active sell and buy orders.
  - `Sell Orders`: Filters to show active sell orders only.
  - `Buy Orders`: Filters to show active buy orders only.
  - `Infinite Orders`: Filters to show active infinite buy orders only.
- **Active Orders Sort Button**: Added interactive `Sort` button in the Active Orders subtab:
  - `Newest`: Sorts orders by creation time descending.
  - `Oldest`: Sorts orders by creation time ascending.
  - `Price ▲`: Sorts orders by price low to high.
  - `Price ▼`: Sorts orders by price high to low.
- **Filter & Sort Persistence**: Selected filter and sort states persist across subtab navigation and GUI re-openings.

### Reorganized Sidebar Navigation
- **Logical Tab Workflow**: Reordered sidebar tabs to follow a clear, natural workflow:
  1. `Browse`
  2. `New Order`
  3. `Orders` (My Orders & History)
  4. `Portfolio`
  5. `Vaults`

# Section 2: Technical Changelog

### Trading Engine & Order Model (`Order.java`, `OrderManager.java`)
- **Uncapped Execution for Infinite Orders**: Fixed `Order.executePartial` tradeQty calculation to `isInfinite ? amountToTrade : Math.min(this.quantity, amountToTrade)`, preventing infinite buy orders from being throttled by `this.quantity`.
- **Order Quantity Preservation**: Fixed `Order.executeBuy` to preserve `quantity` when `isInfinite` is true instead of zeroing out `this.quantity`.
- **Dynamic Initial Quantity**: Added `setInitialQuantity()` in `Order.java` and updated `OrderManager.editOrder()` to sync `initialQuantity` and `quantity` when editing or converting infinite buy orders to non-infinite orders.

### Client UI Improvements (`MarketScreen.java`)
- **Auto-Detection in `submitEditOrder()`**: Updated submit logic to parse `qtyStr` and auto-adjust `editIsInfinite` state depending on whether numeric values or `∞` are present.
- **Digit Key Input Interception**: Added digit character detection in `charTyped()` to clear `∞` symbols and set `editIsInfinite = false` when user types digits.
- **Active Orders List Filtering & Sorting**: Integrated `filterActiveOrders()` and updated `buildActiveOrdersList()` with filter/sort button controls and saved state fields (`savedActiveOrdersFilterMode`, `savedActiveOrdersSortMode`).
- **Sidebar Component Reordering**: Reordered button registration in `MarketScreen.java` sidebar construction pass.
