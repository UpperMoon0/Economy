# Economy 0.0.14

## Team economy foundation

- Add typed economic principals: `PLAYER`, `TEAM`, `SERVER`, and `TAX`.
- Keep the legacy UUID account API source-compatible while adding typed account lookup, creation, deletion, and transfer methods.
- Migrate legacy saved balances deterministically to `PLAYER:<uuid>` and persist non-player principals in a separate version-safe balance section.
- Ensure player starting balance is applied only to newly created player accounts. Team accounts always start at zero.
- Allow a player account and team account to use the same raw UUID without colliding.
- Represent Economy's server and tax accounts with typed identities.
- Preserve typed identities in balance/transfer events and transaction counterparties, with legacy UUID constructors/accessors retained. Add same-UUID player/team event, veto, and history regression tests.

## FTB Teams integration

- Add an optional, loader-neutral team-economy provider contract.
- Auto-register an FTB Teams provider when FTB Teams is installed without introducing a hard dependency.
- Treat only FTB party teams as shared Economy wallets; FTB personal and server teams are intentionally excluded.
- Add `PERSONAL_ONLY`, `HYBRID`, and `TEAM_PRIMARY` account-selection modes. The default remains `PERSONAL_ONLY`.
- Add configurable minimum roles for viewing, depositing, spending, and administration, defaulting to MEMBER / MEMBER / OFFICER / OWNER.
- Re-resolve membership and rank for every authorization check so kicks, leaves, and demotions fail closed.
- Add permission-checked personal→team deposits and team→typed-principal spending/withdrawal helpers so authorization and balance mutation stay in one server-side operation.
- Keep Economy balances in Economy persistence rather than FTB Teams extension data.
- Show separate Personal and Team balances in the Market, with the FTB party display name, current role, configured spend threshold, and an explicit Market principal indicator.
- Hide team wallet UI when team economy is disabled/unavailable or current membership no longer permits viewing; market actions remain explicitly Personal until #29.

## Compatibility and tests

- Add pure-Java regression coverage for typed account identity, starting-balance isolation, persistence, team-mode selection, fresh rank checks, and server-authoritative wallet snapshots.
- Test reflection-adapter behavior with doubles for party filtering, rank mapping, leave/kick revalidation, and fail-closed behavior.
- Verify public reflection signatures against real, pinned FTB Teams jars for all five supported loader/version targets in CI.
- Include pinned FTB Teams and FTB Library in every loader development runtime, while keeping the production integration optional.
- Add saved-data round-trip coverage for Minecraft 1.20.1, Minecraft 1.21.1, and NeoForge 26.1.2, including TEAM/SERVER/TAX principals.
- Market orders remain player-principal operations in this release; team-funded orders are tracked separately by issue #29.
